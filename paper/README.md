# Paper Assets

This directory contains paper and reproducibility assets associated with the
NEJM AI study. These files are not required by the runtime package or CLI.

- `scripts/`: model-training, evaluation, survival-analysis, and table scripts.
- `outputs/`: paper output tables/data files.
- [`provenance/`](provenance/): S0001 training-record identifiers and a
  conservative subject exclusion list for released-model overlap checks.

The runtime package lives under `src/philosophers_stone/`.
