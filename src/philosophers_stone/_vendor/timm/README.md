# Vendored timm Runtime Subset

This directory contains the minimal `timm` runtime files needed to load and
run the Philosopher's Stone MaxxVit-based checkpoint.

The code is derived from `pytorch-image-models` / `timm` by Ross Wightman and
keeps the upstream license in `LICENSE`. It intentionally excludes upstream
documentation, tests, training scripts, benchmark results, and model families
not needed by this package.
